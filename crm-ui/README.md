# crm-ui

Next.js app for the ruab CRM and admin UI. Skeleton only — features and design come later.

## Run

From the repo root:

```bash
./10-crm-ui.sh
```

Dev server: `http://localhost:8100`

## Config

| Variable | Default | Meaning |
|----------|---------|---------|
| `PORT` | `8100` | HTTP port |
