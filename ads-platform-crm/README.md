# ads-platform-crm

CRM and admin application for the ruab ads platform. This is a skeleton; routes and domain logic will be added later.

## Run

From the repo root:

```bash
./10-ads-platform-crm.sh
```

Health: `GET http://localhost:8100/health`

## Config

| Variable | Default | Meaning |
|----------|---------|---------|
| `PORT` | `8100` | HTTP port |
| `APP_NAME` | `ruab CRM` | Display name |
